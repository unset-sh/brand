The contract gives people and tools the same named decisions. Edit a colour, typeface, or component recipe once, regenerate the shared output, and review the result here. Stable role names keep consuming repositories consistent.

  1. Read the role. Use color.ground for a page canvas and color.link for an unvisited content link.
  2. Check its status. Working values are ready to review. Provisional values are candidates, not stable defaults.
  3. Consume one version. Pin the contract and matching assets. Import the package styles and assets rather than copying values by hand.

Import the foundation

The base CSS works in any web interface. Add the Tailwind and shadcn adapters only in applications that use them; the renderer can read the JSON contract directly.

Shared stylesheetCSS
@import "@unset-sh/brand/tokens.css";

.page {
  background: var(--ground);
  color: var(--ink);
  font-family: var(--font-sans);
}

For a Tailwind v4 interface, install tw-animate-css, then add the shadcn adapter and token mapping. The optional recipes supply the shared component refinements shown in the gallery.

Tailwind and shadcn-svelteCSS
@import "tailwindcss";
@import "tw-animate-css";
@import "@unset-sh/brand/tokens.css";
@import "@unset-sh/brand/shadcn.css";
@import "@unset-sh/brand/tailwind.css";
@import "@unset-sh/brand/recipes.css";

@custom-variant dark (&:where([data-theme="dark"], [data-theme="dark"] *));

The adapter targets the gallery’s pinned Vega markup. Set the root appearance and class as shown; data-recipes="true" opts into the shared refinements.

Root elementHTML
<html class="style-vega" data-theme="dark" data-recipes="true">

Use data-theme="light" for the light appearance. Check the consuming component version and markup: CSS updates styling, not copied shadcn component source or behavior.
